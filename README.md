# Waybar Features

This Waybar features: Wofi Menu, Workspaces, Clock (with calendar on hover), Volume Control, Wi-Fi Management, Battery and Notifications Centre.

## How to use

git clone https://github.com/sxntoszzz/waybar-config.git ~/.config/waybar

## Add:

hl.workspace\_rule(\{ workspace = "1", persistent = true, \})

to your hyprland.lua file

## Extern Utilities:

- swaync

- pavucontrol

- wofi
